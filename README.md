# Infection Survival (ชุมชนสู้โรค: Survival Outbreak)

เว็บเกมแนว 2D Top-down Survival เอาชีวิตรอดในชุมชน พร้อมจำลองความเสี่ยงและการป้องกันโรคติดต่อสำคัญ 4 โรค (ไข้เลือดออก, ไข้หูดับ, โรคฉี่หนู, อุจจาระร่วงเฉียบพลัน) พัฒนาด้วยเทคโนโลยี Web มาตรฐาน (HTML5 Canvas, CSS Glassmorphism, Vanilla JavaScript และ Web Audio API)

## 🌟 ฟีเจอร์หลักของเกม

1. **ระบบบริหารความต้องการพื้นฐาน (Survival Needs):**
   - แถบสถานะด้านบน: **❤️ HP**, **🍗 ความหิว (Hunger)**, **💧 น้ำในร่างกาย (Thirst)**, **⚡ พลังงาน/ความง่วง (Energy)**
   - หากขาดน้ำหรืออาหารต่อเนื่อง เลือดจะลดลงจนเสียชีวิต
   - อุปกรณ์ป้องกัน: รองเท้าบูทยาง (👢 ป้องกันฉี่หนู 100%), โลชั่นกันยุง (🧴 ป้องกันยุงลาย)

2. **ระบบจำลอง 4 โรคระบาด & พฤติกรรมเสี่ยง (Epidemiological Rules):**
   - 🦟 **โรคไข้เลือดออก (Dengue Fever):** เสี่ยงเมื่อเดินในดงหญ้ารกช่วงเช้า/พลบค่ำ หรือนอนไม่กางมุ้ง ป้องกันด้วยการคว่ำกะลา ใส่ทรายอะเบทในโอ่งน้ำ กางมุ้ง และทายากันยุง *(ข้อควรระวังทางการแพทย์: ห้ามกินยาแอสไพรินเด็ดขาด เพราะเสี่ยงตกเลือดในทางเดินอาหาร! ให้ใช้พาราเซตามอลเท่านั้น)*
   - 🥩 **โรคไข้หูดับ (Streptococcus suis):** เสี่ยงเมื่อกินเนื้อหมูดิบ/เลือดดิบ ป้องกันด้วยการปรุงสุกที่เตา 100% แยกตะเกียบคีบดิบ-สุก *(เมื่อติดเชื้อจะมีเสียงวิ้งหูดับ Tinnitus และระบบเสียงรอบตัวจะดับสนิท)*
   - 👢 **โรคฉี่หนู (Leptospirosis):** เสี่ยงเมื่อเดินลุยแอ่งน้ำขังหรือโคลนด้วยเท้าเปล่า ป้องกันด้วยการสวมใส่รองเท้าบูทยาง *(เมื่อติดเชื้อ จะปวดน่องรุนแรงจนเดินช้าลง 60%)*
   - 🍲 **อุจจาระร่วงเฉียบพลัน (Acute Diarrhea):** เสี่ยงเมื่อดื่มน้ำดิบจากก๊อก/บ่อน้ำ หรือกินอาหารสุขอนามัยต่ำ ป้องกันด้วยการต้มน้ำให้เดือดสนิทและล้างมือก่อนรับประทานอาหาร *(เมื่อติดเชื้อ หลอดน้ำ Thirst จะลดลงเร็วเป็น 4 เท่า ต้องรีบดื่มผงเกลือแร่ ORS)*

3. **สถานที่และสิ่งอำนวยความสะดวกในชุมชน:**
   - **บ้านผู้เล่น:** เตียงนอน (กางมุ้ง/ไม่กางมุ้ง), เตาไฟทำอาหาร (ย่างหมู/ต้มน้ำ), อ่างล้างมือพร้อมสบู่
   - **ลานบ้าน & ชุมชน:** โอ่งกักเก็บน้ำฝน, กองกะลามะพร้าวขยะน้ำขัง, บ่อน้ำบาดาล
   - **ตลาดชุมชน:** แผงหมูสดลุงสมชาย, ร้านส้มตำป้าณี
   - **สถานีอนามัย (รพ.สต.):** ตรวจสุขภาพ ฉีดยาปฏิชีวนะ ขอรับยาพาราเซตามอล ผงเกลือแร่ ORS บูทยาง และทรายอะเบท

4. **ระบบเสียงสังเคราะห์ในตัว (Web Audio API):**
   - เสียงก้าวเดิน (บนดิน/ย่ำน้ำ), เสียงเคี้ยว/ดื่ม, เสียงไฟเตา, เสียงยุงบินตอม, เสียงหัวใจเต้น และเสียงวิ้งหูดับ โดยไม่ต้องพึ่งพาไฟล์เสียงภายนอก

## 🕹️ การควบคุม (Controls)

- **เคลื่อนที่:** ปุ่ม <kbd>W</kbd> <kbd>A</kbd> <kbd>S</kbd> <kbd>D</kbd> หรือปุ่มลูกศร (หรือ Virtual Joystick บนหน้าจอมือถือ)
- **สำรวจ / โต้ตอบ:** ปุ่ม <kbd>E</kbd> หรือปุ่มทำรายการบนหน้าจอ
- **ใช้ไอเทมในกระเป๋าเป้:** ปุ่มตัวเลข <kbd>1</kbd> - <kbd>8</kbd> หรือคลิกที่ช่องไอเทม
- **ยกเลิก / ปิดหน้าต่าง:** ปุ่ม <kbd>Esc</kbd>

## 🚀 วิธีเปิดใช้งานเกม

1. สามารถดับเบิลคลิกเปิดไฟล์ `index.html` บนเว็บเบราว์เซอร์ได้โดยตรง หรือ
2. รัน Local HTTP Server:
   ```bash
   python -m http.server 8080
   ```
   แล้วเปิดเบราว์เซอร์ไปที่ `http://localhost:8080`
